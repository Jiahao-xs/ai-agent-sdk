## 快速开始

### 1. 环境要求

- Node.js >= 18
- pnpm >= 8
- **uv**（可选，MCP 天气工具需要）：用于运行 `uvx weather-forecast-server`
  - Windows: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`
  - macOS/Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
  - 安装后验证: `uvx --version`

### 2. 配置环境变量

```bash
cd examples/web-demo
cp .env.example .env
```

编辑 `.env` 文件，填入你的 OpenAI API Key：

```env
OPENAI_API_KEY=sk-your-actual-key
OPENAI_API_BASE=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
PORT=3001
```

> 如使用国内代理或其他 OpenAI 兼容服务，修改 `OPENAI_API_BASE` 即可。

### 3. 安装依赖

```bash
# 确保 SDK 根目录已构建
cd ../../../          # 回到项目根目录
pnpm run build        # 构建 ai-agent-sdk

# 安装 web-demo 依赖
cd examples/web-demo
pnpm install
```

### 4. 启动开发服务器

```bash
# 并发启动前后端
pnpm run dev
```

- 前端: http://localhost:5173
- 后端: http://localhost:3001

也可以单独启动：

```bash
pnpm run dev:server   # 仅后端
pnpm run dev:client   # 仅前端
```

### 5. 使用

打开浏览器访问 http://localhost:5173，即可与 AI 助手对话。

**示例提问：**

- `计算 (123 + 456) * 7` — 触发 calculator 工具
- `现在几点了？` — 触发 date_time 工具
- `北京今天天气怎么样？` — 触发 MCP 天气工具（需安装 uv）
- 任何问题 — 纯 LLM 对话

## API 接口

### POST /api/chat

发送消息并接收 SSE 流式响应。

**请求：**

```json
POST /api/chat
Content-Type: application/json

{ "message": "你好" }
```

**响应：** `Content-Type: text/event-stream`

SSE 事件按顺序推送：

| 事件类型     | 数据格式                                                    | 说明               |
| ------------ | ----------------------------------------------------------- | ------------------ |
| `token`      | `{ "content": "你" }`                                       | LLM 生成的文本片段 |
| `tool_start` | `{ "tool": "calculator", "args": { "expression": "1+2" } }` | 工具开始调用       |
| `tool_end`   | `{ "tool": "calculator", "result": "3" }`                   | 工具调用完成       |
| `done`       | `{ "output": "完整回复", "duration": 1234 }`                | 本轮对话完成       |
| `error`      | `{ "message": "错误描述" }`                                 | 发生错误           |

**SSE 流示例：**

```
event: token
data: {"content":"根据"}

event: token
data: {"content":"计算"}

event: tool_start
data: {"tool":"calculator","args":{"expression":"(123+456)*7"}}

event: tool_end
data: {"tool":"calculator","result":"4053"}

event: token
data: {"content":"计算结果是 4053"}

event: done
data: {"output":"计算结果是 4053","duration":2345}
```

### GET /api/health

健康检查接口。

```json
{ "status": "ok", "timestamp": "2026-06-09T10:00:00.000Z" }
```

## 架构说明

```
┌─────────────┐    SSE     ┌─────────────┐    SDK     ┌──────────┐
│  React 前端  │ ◄──────── │ Express 后端 │ ◄──────── │ OpenAI   │
│  (Vite:5173) │ ────────► │ (Port:3001) │ ────────► │ API      │
└─────────────┘  POST/     └─────────────┘  stream()  └──────────┘
                 fetch()                       │
                                               ├─► Skill 插件（prompt + 工具注入）
                                               ├─► MCP 天气工具（uvx 子进程）
                                               └─► 内置工具（calculator/date_time）
```

- **前端** 通过 `fetch` 发送 `POST /api/chat`，用 ReadableStream 读取 SSE 事件流
- **后端** 调用 ai-agent-sdk 的 `createAgent().stream()` 方法，将 LLM 输出通过 SSE 推送
- **Skill 插件** 从 `examples/skills/` 目录加载 SKILL.md，自动注入 prompt、工具和 MCP 配置
- **MCP 工具** 通过 Skill 声明的 `mcpServers` 自动启动 MCP 子进程（如天气服务）
- **开发模式** Vite 代理 `/api` 请求到后端，无需处理 CORS
- **工具调用** Agent 调用工具时，前端实时展示调用过程和结果

## 代码规范

- **Prettier**: 前后端共享 `.prettierrc`，统一代码风格（`endOfLine: "auto"` 跨平台兼容）
- **ESLint**: 后端 `@typescript-eslint + prettier`，前端额外增加 `react + react-hooks` 规则
- **TypeScript**: 严格模式，`consistent-type-imports` 强制类型导入
- **Husky + lint-staged**: `git commit` 时自动对暂存文件执行 ESLint 修复和 Prettier 格式化

## 自定义扩展

### 更换 LLM 模型

编辑 `server/src/agent.ts`：

```typescript
// 使用配置对象模式（支持其他 OpenAI 兼容服务）
createAgent({
  model: {
    provider: 'openai',
    name: 'deepseek-chat',
    apiKey: process.env.DEEPSEEK_API_KEY,
    basePath: 'https://api.deepseek.com/v1',
  },
  tools: [calculatorTool, dateTimeTool],
  prompt: '你的自定义提示词',
});
```

### 添加自定义工具

```typescript
import { defineTool } from 'ai-agent-sdk';
import { z } from 'zod';

const weatherTool = defineTool({
  name: 'weather',
  description: '查询城市天气',
  parameters: z.object({ city: z.string() }),
  execute: async ({ city }) => `${city}今天晴，25°C`,
});

// 在 agent.ts 中注册
createAgent({ model: 'gpt-4o-mini', tools: [weatherTool] });
```

### 添加 Skill 技能

在 `examples/skills/` 下创建新目录和 `SKILL.md` 文件：

```markdown
---
name: my-skill
description: 我的自定义技能
tools:
  - calculator
mcpServers:
  some-server:
    command: npx
    args: ['-y', 'some-mcp-server']
---

你是一个...（角色描述和能力说明）
```

SDK 会自动加载并注入 prompt、工具和 MCP 配置，无需修改代码。

### 修改前端样式

编辑 `client/src/styles/app.css`，所有样式集中在此文件。

## 常见问题

**Q: 启动后端报错 `Cannot find module 'ai-agent-sdk'`**

确保项目根目录已执行 `pnpm run build`，SDK 的 `dist/` 目录需存在。

**Q: 前端请求 404**

确保 Vite 代理配置正确（`client/vite.config.ts` 中 `proxy` 字段），且后端已启动在 3001 端口。

**Q: LLM 响应为空或报错**

检查 `.env` 中的 `OPENAI_API_KEY` 是否正确，`OPENAI_API_BASE` 是否可访问。

**Q: 天气工具调用失败**

天气 MCP 工具依赖 `uvx` 命令，需先安装 `uv`。未安装时 SDK 会优雅降级（跳过 MCP 工具），不影响正常对话。
